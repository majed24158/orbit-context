# Orbit Context

أدوات ملفات لويندوز تظهر عند الضغط بزر الماوس الأيمن على صورة أو PDF أو Word أو TXT. الإصدار **1.2**.

## الاستخدام

1. حمّل الحزمة من قسم **Releases** وفك الضغط.
2. شغّل `OrbitContext.exe` واضغط **تثبيت / تحديث قسم الأدوات** مرة واحدة.
3. أغلق الإعدادات، ثم اختر ملفًا بزر الماوس الأيمن ← **أدوات الملفات — Orbit**.

قد تحتاج في Windows 11 إلى **إظهار المزيد من الخيارات**. الحفظ الافتراضي بجانب الأصل كنسخة جديدة؛ لا يُستبدل أي ملف موجود.

## الأدوات

- الصور: تحويل الصيغة، ضغط، قص، مقاس، تدوير ورسم.
- PDF: تحويل الصفحات إلى صور وتحسين الضغط.
- Word إلى PDF: يستخدم Word المثبّت مخفيًا وللقراءة فقط.
- الصور وPDF إلى Word قابل للتحرير أو TXT عبر Codex المحلي.
- TXT إلى Word، أو تنسيق TXT بنص بسيط أو Markdown أو Tab أو تعليمات مخصصة محفوظة.

تحتاج أدوات Word إلى نسخة سطح المكتب المثبتة والمفعلة. ويحتاج التحويل الذكي إلى Codex مثبت ومسجل الدخول. أدوات الصور وPDF المحلية تعمل دون إرسال المحتوى إلى Codex.

## الخصوصية والدقة

التحويل الذكي يرسل محتوى الملفات المختارة إلى خدمة النموذج عبر حساب Codex المتصل، بعد تفعيل السماح من الإعدادات. تشغيل Codex محليًا لا يعني أن الاستدلال دون إنترنت.

المطابقة التامة غير مضمونة. النصوص داخل صناديق Word أصلية قابلة للتحرير، والجداول خلايا أصلية، والصور والشعارات قصاصات صور. الخط الحالي Arial، وقد يحتاج النص الطويل إلى تكبير الصندوق بعد التحرير. راجع الأرقام والأجزاء غير الواضحة. الحد الحالي 40 صفحة للتحويل الذكي، ومليون بايت لـTXT.

## التطوير والبناء

المشروع يستهدف Windows x64 وPython 3.14. ثبّت المتطلبات ثم شغّل:

```powershell
python -m pip install -r requirements.txt
python app/orbit_context.py
.\scripts\build.ps1
```

ينتج البناء `dist/OrbitContext.exe`. تثبيت القائمة من المصدر يتطلب بناء EXE أولًا. الفحوص المحلية:

```powershell
python -m unittest discover -s tests -v
```

تجد التفاصيل في [README](README.md) و[دليل الفحص](docs/TESTING.md). اختبارات Word وCodex الحقيقية اختيارية ولا تعمل ضمن CI.
