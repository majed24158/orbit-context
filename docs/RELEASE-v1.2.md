# Orbit Context v1.2

Windows Explorer tools for images, PDF, Word and TXT.

- Hidden native Word-to-PDF export.
- Images/PDF to editable Word or TXT through the installed Codex CLI.
- TXT-to-Word and saved custom text formatting instructions.
- Same-folder copies, collision-safe file names and cancellation.

Download and extract **Orbit-Context-Windows-v1.2.zip**, run **OrbitContext.exe**, and click **تثبيت / تحديث قسم الأدوات** once. Windows 11 may show the menu under **Show more options**.

Word desktop is required for native export/review. Smart conversion requires authenticated Codex and sends chosen content to the model service. Reconstruction is approximate; review the result. The binary is unsigned.

The asset is the original user-supplied v1.2 archive. See `docs/release-manifest.json` for its SHA-256. Source, build scripts and license notices are available in the repository.
