# Orbit Context

برنامج أدوات الملفات لويندوز من قائمة الزر الأيمن.

[تحميل البرنامج EXE](https://github.com/majed24158/orbit-context/raw/refs/heads/main/OrbitContext.exe) · [تحميل جميع الملفات ZIP](https://github.com/majed24158/orbit-context/archive/refs/heads/main.zip)

شغّل `OrbitContext.exe` واضغط **تثبيت / تحديث قسم الأدوات** مرة واحدة.

- `OrbitContext.exe`: البرنامج الجاهز للتشغيل.
- `source`: المصدر الأصلي.
- `licenses`: تراخيص المكتبات.
- `اقرأني.txt`: تعليمات الاستخدام الأصلية.
